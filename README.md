# @ankhorage/orchestrator-module-expo-google-fonts

`@ankhorage/orchestrator-module-expo-google-fonts` is the standalone Google Fonts module extracted for `@ankhorage/orchestrator`. It replaces the old plugin-kit Google Fonts plugin with a pure module that only returns supported orchestrator actions.

The repo follows the module-owned template pattern: generated runtime files come from checked-in [`templates/*.tpl`](./templates) assets that the module reads and materializes into orchestrator `write-files` actions.

## What It Does

- ensures `expo-font`
- ensures one `@expo-google-fonts/*` package per configured font
- writes the Google Fonts runtime files into `src/plugins/google-fonts`
- patches `src/app/_layout.tsx` to wrap the generated app shell with `GoogleFontsProvider`
- syncs `ankh.config.json` with the configured fonts and active font id

The module does not implement font search, Studio modal UI, network proxying, or direct install/remove execution logic. It only emits `ensure-packages`, `write-files`, `patch-text-block`, and `json-set`.

## Install

```sh
bun add @ankhorage/orchestrator @ankhorage/orchestrator-module-expo-google-fonts
```

## Usage

```ts
import { createOrchestrator } from '@ankhorage/orchestrator';
import { expoGoogleFontsModule } from '@ankhorage/orchestrator-module-expo-google-fonts';

const orchestrator = createOrchestrator({
  modules: [expoGoogleFontsModule],
  projectRoot: '/absolute/path/to/project',
});

await orchestrator.installModule('expo-google-fonts', {
  config: {
    installedFonts: [
      {
        id: 'inter',
        family: 'Inter',
        weights: [400, 700],
        styles: ['normal', 'italic'],
      },
    ],
    activeFontId: 'inter',
  },
});
```

## Config

```ts
{
  installedFonts?: {
    id: string;
    family: string;
    weights?: number[];
    styles?: string[];
  }[];
  activeFontId?: string | null;
}
```

Defaults:

- `installedFonts`: `[]`
- `activeFontId`: `null`

## Assumptions

- The target app already has a generated `src/app/_layout.tsx`.
- The target app uses the standard `@/` alias layout generated by the surrounding Ankhorage toolchain.

This package is meant for the `@ankhorage/orchestrator` stack and supersedes the old `@ankh/plugin-kit` Google Fonts plugin path that is planned for removal.
